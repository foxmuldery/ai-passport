# 烦恼种子 · AI Passport

这是一个完全离线的语音陪伴应用：把烦恼录成一颗种子，每次记录解决过程都会让它从种子、发芽、幼苗逐步长成树；问题解决后，树会结出果实。

## 使用

- 种子园：上下切换种子，确定查看，长按确定播种。
- 播种：选择工作、关系、家庭、健康或其他，然后录制最长 60 秒的语音。
- 陪伴：可以听最初的烦恼、增加最多 5 次进展、标记解决或删除种子。
- 所有元数据保存在 NVS，录音保存在设备的 `worryfs` 分区，不上传网络。

录音采用 8 kHz 单声道 IMA ADPCM，最长一条约 240 KB。设备最多保存 12 颗种子，5 MB 录音分区可容纳约 20 条满时长录音，实际容量取决于录音长度。

## 构建

使用 ESP-IDF 5.5.3：

```sh
./tools/validate.sh --static
./tools/validate.sh --firmware
```

合并固件输出为 `build/FoloToy-AI-Passport-full.bin`，烧录地址为 `0x0`。烧录前请先获得设备所有者确认。

## 数据安全

新录音先写入临时文件，完成后再原子改名；花园元数据带版本与 CRC。固件不启用 Wi-Fi 或蓝牙。首次挂载损坏的录音分区时 SPIFFS 会格式化，因此重要录音不应只保存在设备上。
