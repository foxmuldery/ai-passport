# 烦恼种子主题资源

这里保存用户提供的美术包和固件可用的主题资源。

## 目录结构

- `source/`：原始独立风格图、历次总览、过程预览和原始清单。
- `derived/`：裁切后的 240×320 主视觉，以及带透明层的成长阶段和图标 PNG。
- `firmware/`：嵌入 ESP32-C3 固件的 RGB565 背景和 RGB565A8 语义分层资源。
- `theme-assets.json`：背景源文件、裁切坐标、尺寸、字节数和 SHA-256 清单。
- `derived/theme-layers.json`：五个成长阶段和十个控制图标的可复现裁切坐标与校验值。

当前运行时主题为 `pixel`、`watercolor`、`realistic`、`ink`、`starlight`。主题切换会同时改变配色、主视觉和页面引导文案，但不会改变交互逻辑。

设备端在花园页长按上键或下键切换主题，选择结果保存到 NVS，重启后恢复。长按确定键仍然保持原有含义：开始播种新的烦恼。

用户提供的原图是展示板，不是拆分后的独立文件。`tools/build_worry_seed_theme_assets.py` 会在不改动原图的前提下提取语义层。当前运行时主题已经同时提供背景、五个成长阶段前景，以及水滴、叶片、果实、麦克风、播放、停止、返回、上下、确认等主题化控件；中文文案仍由设备字体渲染，便于独立检查字体覆盖。
