# 烦恼种子：主题美术与出图规范

## 1. 项目目标

“烦恼种子”是一款把烦恼记录、倾诉、进展和解决过程可视化的硬件应用。

核心隐喻：

> 种下烦恼，用努力浇灌；一点点改变，也会发芽；坚持下去，烦恼会长成力量。

本项目采用“同一套交互逻辑，多套主题皮肤”的设计方式。未来切换主题时，只替换背景、植物素材、图标、动画参数和提示音，不改变按键操作、录音逻辑和数据结构。

## 2. 设备与画布约束

- 设备屏幕：240 × 320，竖屏，3:4 比例
- 网页生图建议尺寸：768 × 1024 或 1536 × 2048
- 画面必须适合缩小到 240 × 320 后仍清晰
- 主体放在画面中央，四周保留约 15% 安全区域
- 避免过细线条、过多小物件和复杂纹理
- 需要足够的明暗对比，保证低亮度屏幕可读
- 所有成长阶段必须保持同一个种子、树干、树冠和果实造型

## 3. 每套主题必须输出的素材

### 主界面素材

1. 花园空状态：还没有种子
2. 种子状态
3. 发芽状态
4. 小树状态
5. 成树状态
6. 结果实状态
7. 录音/倾诉界面
8. 进展详情界面
9. 开花庆祝界面

### 通用图标与效果

- 水滴
- 叶子
- 果实
- 麦克风
- 播放
- 停止
- 返回
- 上下选择箭头
- 确认符号
- 光点、花瓣、星尘或像素粒子

### 分层要求

- 全屏背景：独立输出
- 种子/树/果实主体：透明背景 PNG
- 粒子、光晕、花瓣等效果：独立透明图层
- 不要把中文、按钮、数字、Logo 或水印直接生成到图片中
- 文字由设备端字体绘制

## 4. 主题方向

## 4.1 治愈像素风（首推）

### 关键词

像素风、温暖、怀旧、治愈、低饱和、精致 16-bit 像素画。

### 视觉方向

- 深绿色背景与米白色文字区域
- 种子从小点逐渐变成完整果树
- 用像素块表现水滴、叶片、果实和光点
- 适合轻微上下浮动、闪烁和粒子动画
- 在 240 × 320 屏幕上最容易保持清晰

### 推荐配色

```text
背景：#1D2A27
米白：#F6F1DE
嫩绿：#82A86B
深绿：#42634E
土壤：#9B7048
果实：#E77B68
高光：#F5D98A
```

### 网页生图提示词

```text
治愈系像素风互动电子产品界面，
主题是“把烦恼种成一棵树”，
竖屏 3:4 构图，中心是一颗小小的烦恼种子，
温暖米白与深绿色背景，
精致 16-bit 像素画，
柔和高光，清晰轮廓，低饱和配色，
画面简洁，适合缩小到 240x320 LCD，
不要文字，不要按钮，不要 Logo，不要水印，
主体和背景分层，透明背景主体素材。
```

## 4.2 浪漫水彩风

### 关键词

水彩、手账、花园、柔光、浪漫、情绪疗愈。

### 视觉方向

- 奶油白、粉绿、珊瑚色
- 树像手绘植物插画
- 种子带有露珠和柔和高光
- 果实可以是星星、心形或小灯笼
- 倾诉时出现柔和呼吸光
- 开花时加入花瓣和光点

### 推荐配色

```text
纸张：#FFF8E8
鼠尾草绿：#A8C3A0
玫瑰粉：#E7A39B
天空蓝：#A9C8D8
暖金：#E8C979
```

### 网页生图提示词

```text
浪漫治愈系水彩插画风，
主题是“种下烦恼，慢慢长成力量”，
竖屏 3:4，
一颗小种子在柔和土壤中发芽并成长为小树，
奶油纸张质感，鼠尾草绿、珊瑚粉、暖金色，
轻柔水彩晕染，细腻手绘边缘，
留出大面积干净留白，
适合电子设备 UI 背景和分层动画，
不要文字，不要 Logo，不要水印。
```

## 4.3 微缩写实风

### 关键词

微缩摄影、真实植物、桌面花园、电影光线、自然疗愈。

### 视觉方向

- 像放在桌面上的小型生态瓶
- 种子、泥土、树叶和果实具有真实材质
- 背景虚化，主体轮廓必须清楚
- 果实可以是发光的小果子，代表问题解决
- 避免过多真实细节导致小屏幕缩放后糊成一团

### 网页生图提示词

```text
微缩写实摄影风格的治愈系电子产品视觉，
主题是“烦恼种子成长为希望之树”，
竖屏 3:4，
一个精致的小型桌面生态花园，
清晰可见的种子、泥土、嫩芽、小树和果实，
柔和自然光，浅景深，但主体轮廓清楚，
色彩温暖、干净、宁静，
适合缩小到 240x320 屏幕，
不要文字，不要 UI 按钮，不要 Logo，不要水印。
```

## 4.4 东方山水 / 水墨风

### 关键词

东方、留白、水墨、竹叶、山石、禅意、成长。

### 视觉方向

- 用一颗种子、一方土和一株树表达心境
- 背景可以是淡墨山水或窗格
- 每次进展增加一片叶、一枝花或一枚果实
- 适合搭配简短的成长提示语
- 可以加入金色光晕，但不要生成带文字的印章

### 推荐配色

```text
墨色：#26382E
宣纸：#F3EBD4
竹青：#66846B
赭石：#A7774D
朱砂：#D77A61
```

### 网页生图提示词

```text
东方治愈系水墨插画，
主题是“种下烦恼，用时间和努力浇灌”，
竖屏 3:4，
一颗种子在宣纸质感的土地中逐渐长成树，
淡墨山水、竹叶、留白、少量赭石和朱砂色点缀，
现代简洁构图，主体清晰，
适合电子设备小屏幕，
不要任何文字、印章文字、Logo 或水印。
```

## 4.5 星空梦境风

### 关键词

夜空、星星、梦境、发光植物、安静、希望。

### 视觉方向

- 深蓝或紫蓝背景
- 种子像一颗小星球
- 每次进展增加一颗星光
- 果实像小月亮或星星
- 录音时显示星光波纹
- 适合夜间陪伴主题

### 网页生图提示词

```text
梦幻治愈系星空植物视觉，
主题是“把烦恼种进夜空，长出希望”，
竖屏 3:4，
一颗发光的小种子逐渐长成星光树，
深蓝、靛紫、柔和金色，
细小星尘、月光、发光果实，
宁静、温柔、具有陪伴感，
主体轮廓清晰，适合 240x320 LCD，
不要文字，不要 Logo，不要水印。
```

## 5. 推荐制作顺序

1. 治愈像素风：最适合当前硬件和动画验证
2. 东方水墨风：建立产品辨识度
3. 浪漫水彩风：强化情绪疗愈与礼物感
4. 星空梦境风：作为夜间主题
5. 微缩写实风：作为高质感实验主题

## 6. 主题资源结构建议

```text
theme_id
palette
background_assets
growth_stage_assets
icon_assets
animation_profile
tone_profile
```

建议主题 ID：

```text
pixel
watercolor
ink
starlight
realistic
```

每套主题只替换：

- 背景图
- 种子、树、果实素材
- 图标
- 动画参数
- 播种、倾诉、开花提示音

按键逻辑、录音逻辑、进展记录和数据格式保持不变。这样网页版生成新主题后，可以直接替换资源包，不需要重写整个应用。

## 7. 当前建议

第一套建议先制作“治愈像素风”完整素材包，先验证：

- 240 × 320 屏幕上的可读性
- 种子到果树的五阶段一致性
- 上下浮动和开花动画
- 播种、倾诉、开花提示音与画面同步
- 中文字体与插画的对比度

验证通过后，再把同一套布局迁移到水彩、水墨和星空主题。
