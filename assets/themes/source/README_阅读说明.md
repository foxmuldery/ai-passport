## 文件来源与限制

1. 现存的8张生成原图全部保留了原文件字节、尺寸和格式。像素第二版位于第一目录，没有在第二目录重复存放。同一原文件的重复挂载副本不重复打包。
2. 最后展示的四张非像素独立版PNG未在当前文件中保留，因此本包从现存的第三版五风格总览原图重新拆分、左右排版导出，并在文件名中标注“重排导出”。它们不是此前展示PNG的逐字节恢复，布局边距可能不同。此次没有重新调用图像生成模型。

5. 所有图片均为现阶段美术展示、素材汇总或过程检查图，不等同于已完成逐元素透明分层、动画切图或240×320设备端资源适配。
