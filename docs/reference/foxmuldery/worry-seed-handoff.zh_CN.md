- 当前本地分支：`feature/worry-seed-experience`。
- 本快照记录时，GitHub 已发布分支仍是停在最初 `783ba34` 功能提交的 `feature/worry-seed`；当前工作区尚未提交或推送。

## 产品文案

- 宣传主句：**说出来，埋在土里，等它结果开花。**
- 设备空花园页面保留更短的提示语，以适应 240 像素宽度。
- 用户文案统一使用“浇灌”，不再使用“陪伴”或自动治愈式表达。
- 应用不承诺所有烦恼都会解决，也不提供医疗或诊断结论。

## 产品行为

每个说出的烦恼成为一颗种子；后续进展录音推动它经历五个视觉阶段；用户确认旧烦恼已经解决后，它会成为果实，并播放庆祝旋律。

| 阶段 | 规则 | 画面 |
| --- | --- | --- |
| 种子 | 0 次进展 | 土里的种子 |
| 发芽 | 1 次进展 | 新芽 |
| 幼苗 | 2–3 次进展 | 小植株 |
| 成树 | 4–5 次进展 | 完整树木 |
| 结果 | 标记问题已解决 | 成长的果实 |

花园最多保存 12 颗种子。每颗包含 1 条初始录音和最多 5 条进展录音；分类为工作、关系、家庭、健康和其他。详情页可以播放最初的烦恼、播放最近的进展、记录新的进展、标记解决、删除或返回。

## 持久化与音频

花园元数据存放在 NVS 命名空间 `worryseed`、键 `garden` 中，包含魔数、存储版本、结构大小、模型和 CRC-32；无效数据会回退为空花园。

录音位于 5 MiB 的 `worryfs` SPIFFS 分区，文件名 `/worry/rNNNNN.wsad`。先写 `.tmp`，成功后再原子改名。格式为 8 kHz 单声道、16 位采集、4 位 IMA ADPCM，最长 60 秒。满时长约 240 KB 加文件头，分区大约容纳 20 条满时长录音，实际容量随时长变化。

SPIFFS 挂载失败时允许格式化，因此重要录音不能只保存在设备中。从 `0x0` 写入会写 bootloader、分区表和应用，但不主动整片擦除；旧分区布局不兼容时，数据仍可能不可读或在挂载失败后被格式化。

## 本地接续

当前修改必须先提交并推送，新的克隆才能切换到 `feature/worry-seed-experience`：

```sh
git clone https://github.com/foxmuldery/ai-passport.git
cd ai-passport
git switch feature/worry-seed-experience
source /path/to/esp-idf-v5.5.3/export.sh
./tools/validate.sh
shasum -a 256 build/FoloToy-AI-Passport-full.bin
```

发现 USB 端口只是只读检查，不代表允许刷机。获得明确确认后，写入准确的已验证合并固件，不要增加 `erase_flash`：

```sh
python -m esptool --chip esp32c3 --port /dev/cu.usbmodemXXXX \
  --baud 460800 write_flash 0x0 build/FoloToy-AI-Passport-full.bin
```

5. 增加 5 次进展并检查全部成长阶段。
6. 标记解决并重启，确认果实仍然存在。
7. 删除种子并重启，确认元数据和相关录音仍被删除。
8. 接近存储上限，确认明确报错且不破坏已有录音。

## 已知边界

- 完全离线，不做转写、自动分类、同步、上传或 AI 判断。
- 暂无录音导出或备份通道。
- 开始录音前按完整 60 秒预留空间。
- USB 截图代表 LVGL 输出，不能证明每次 LCD SPI 传输都到达面板。
- USB 模拟按键不能验证 ADC 电阻梯、实体开关或硬件消抖。
- 额外主题文件会占用 Flash，但当前体验不能选择这些主题。
